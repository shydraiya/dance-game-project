Per-song Pattern Test backgrounds go in this folder.

Recommended image: PNG or JPG, 1920x1080, 16:9.
Recommended video: MP4 (H.264), 1920x1080, 16:9, 30 fps, 8-12 Mbps.
Video audio is ignored because the selected song is played separately.

Set backgroundPath in Assets/Data/songData.csv to the filename, for example:
billie_jean_stage.mp4

PNG, JPG/JPEG, MP4, WebM, and MOV are accepted. MP4/H.264 is recommended
for the most reliable Windows standalone playback.
